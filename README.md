# demorepo

## 사용자 플로우 문서

### 1) 사용자 플로우: “스토리 입력 → 장면 분할 → 장면별 비디오 생성 → 마지막 장면 자동 연장”
1. **스토리 입력**
   - 사용자가 전체 스토리(자연어 텍스트)를 입력한다.
   - 시스템은 스토리를 저장하고, 이후 단계에서 사용할 메타데이터(언어, 톤, 길이 목표 등)를 확보한다.
2. **장면 분할**
   - 스토리를 장면 단위로 분할한다.
   - 분할 기준(문단, 감정 전환, 장소 전환 등)에 따라 각 장면을 리스트로 생성한다.
3. **장면별 비디오 생성**
   - 각 장면의 텍스트를 비디오 생성 프롬프트로 변환한다.
   - 장면별 기본 길이를 적용하여 장면 비디오를 생성한다.
4. **마지막 장면 자동 연장**
   - 전체 영상의 총 길이가 목표 길이에 부족하면 마지막 장면을 자동으로 확장한다.
   - 확장된 마지막 장면을 기존 장면들과 합성하여 최종 비디오를 출력한다.

### 2) 길이 결정 (목표 총 길이와 장면별 기본 길이)
- **목표 총 길이**: 5분 (300초)
- **장면별 기본 길이**: 20초
- **기본 계산 예시**
  - 총 300초 ÷ 20초 = 15장면
  - 실제 장면 수가 15보다 적으면, 마지막 장면 연장을 통해 부족분을 보정한다.
  - 실제 장면 수가 15보다 많으면, 장면별 길이를 20초 기준으로 유지하되 총 길이는 300초를 초과할 수 있다.

### 3) 마지막 장면 연장 규칙
- **규칙 1: 총 길이 부족분만큼 마지막 장면을 추가 생성**
  - 계산: `부족분 = 목표 총 길이 - (장면 수 × 장면별 기본 길이)`
  - `부족분 > 0`인 경우에만 마지막 장면을 `부족분`만큼 추가 생성한다.
- **규칙 2: 마지막 장면의 키프레임/프롬프트 유지**
  - 마지막 장면의 키프레임, 주요 프롬프트, 스타일 파라미터를 그대로 사용한다.
  - 연장 구간은 동일한 톤과 구성을 유지하되, 자연스러운 흐름을 위해 프롬프트에 “지속/반복/완만한 전개” 등의 보정 문구를 추가할 수 있다.

### 4) 스토리 → 장면 분할 기준
- **문단 기준**: 문단 구분이 명확한 경우 각 문단을 장면으로 분할한다.
- **감정 전환**: 감정의 고조/완화/전환이 발생하는 지점에서 장면을 구분한다.
- **장소 전환**: 배경(장소)이 변경되는 경우 장면을 분리한다.
- **시간 전환**: 과거 회상, 시간 점프 등 시간이 변경되는 지점을 장면 경계로 지정한다.
- **핵심 사건 변화**: 이야기의 주요 사건이 바뀌는 지점을 분할 포인트로 삼는다.
