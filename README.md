# Book Travel (북 트래블)

Book Travel은 내가 읽은 종이책을 다른 사람에게 건네며 그 여정을 함께 기록하는 커뮤니티 플랫폼입니다. 사용자는 책의 ISPN(ISBN) 바코드를 스캔하고, `david183` 과 같은 개인 식별용 접미사를 덧붙여 고유한 Book Travel ID를 생성합니다. 예를 들어 `979-11-98483-43-7 93200`이라는 ISPN에 `-david183`이 붙어 `979-11-98483-43-7 93200-david183` 형태로 등록됩니다. 책이 다음 독자에게 전달될 때마다 해당 ID를 다시 스캔해 체크인을 기록하면, 책이 여행한 경로와 독자의 후기가 지도 위에 표시됩니다.

## 핵심 가치
- **여정을 지도에 기록**: 독서가 끝날 때마다 체크인을 남기면 세계 지도에 책의 이동 경로가 시각화됩니다.
- **독서 경험 공유**: 리뷰, 사진, 코멘트를 남겨 책을 읽은 사람들과 감상을 나눕니다.
- **고유한 책 코드**: 동일한 ISPN이라도 사용자별 접미사가 붙은 Book Travel ID 덕분에 개별 책의 여행을 추적할 수 있습니다.
