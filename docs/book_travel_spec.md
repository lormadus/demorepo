# Book Travel 제품 기획서

## 1. 서비스 개요
Book Travel은 "내가 읽은 책의 다음 여행"을 기록하는 독서 공유 플랫폼입니다. 사용자는 책의 ISPN(ISBN) 번호를 스캔하고, 자신만의 접미사(예: `david183`)를 붙여 고유한 Book Travel ID를 생성합니다. 동일한 ISPN이라도 접미사가 다르면 각각 별도의 여행 기록이 관리됩니다. 책을 전달받은 독자가 다시 Book Travel ID를 스캔해 체크인을 남기면, 지도 위에서 책의 이동 경로와 독서 후기, 대화가 실시간으로 이어집니다.

## 2. 주요 사용자 시나리오
1. **책 등록과 출발**
   - 사용자는 모바일 앱에서 ISPN을 스캔하거나 직접 입력합니다.
   - 기본 책 정보(제목, 저자, 표지)를 외부 API로 자동 조회합니다.
   - 사용자는 나만의 접미사를 입력하고, 추가 메모나 첫 번째 후기를 작성합니다.
   - 생성된 Book Travel ID와 QR 코드를 출력하거나 공유하여 다음 독자에게 전달합니다.
2. **여행 중인 책 탐색**
   - 홈 화면에서 지도 또는 리스트 형태로 현재 여행 중인 책을 탐색합니다.
   - 관심 있는 책을 선택하면 이동 경로와 누적 후기를 확인할 수 있습니다.
   - 위치 필터(도시/국가), 장르 필터, 최근 업데이트 순 정렬을 지원합니다.
3. **독서 완료 후 체크인**
   - 사용자는 전달받은 책의 QR 코드나 ID를 스캔합니다.
   - 현재 위치를 지도에서 선택하거나 GPS로 자동 인식합니다.
   - 독서 후기(텍스트, 평점, 사진)를 남기고 다음 독자에게 전달 여부를 표시합니다.
4. **커뮤니케이션**
   - 후기 상세 화면에서 다른 사용자와 댓글로 대화합니다.
   - 책을 팔로우하여 새로운 체크인, 후기 업데이트 알림을 받습니다.

## 3. 핵심 기능 목록
- **고유 Book Travel ID 생성**: ISPN + 사용자 접미사를 조합하여 중복 없는 ID를 발급.
- **지도 기반 트래킹**: 각 체크인 위치를 지도에 핀으로 표시하고, 이동 타임라인을 제공.
- **독서 기록 공유**: 텍스트/사진 리뷰, 별점, 감정 태그를 지원.
- **소셜 인터랙션**: 댓글, 좋아요, 팔로우, 알림 기능.
- **책 전달 흐름 지원**: QR 코드 생성, 전달 상태 표시(다음 독자 찾는 중 / 전달 완료 / 보관 등).
- **프라이버시 제어**: 위치 정확도(정확 / 동네 / 도시 단위), 공개 범위(전체 / 팔로워 / 비공개) 설정.

## 5. 서비스 흐름
1. **등록 플로우**: ISPN 스캔 → 접미사 입력 → 메타데이터 확인 → Book Travel ID 생성 → 첫 체크인 기록.
2. **체크인 플로우**: Book Travel ID 스캔 → 현재 위치 확인 → 후기/사진 업로드 → 공유 범위 설정 → 저장.
3. **지도 탐색 플로우**: 지도 초기 로딩 → 가까운 책/관심 카테고리 필터 → 상세 보기 → 팔로우/댓글.

각 플로우는 오류 처리(네트워크 끊김, 바코드 미인식, 위치 권한 미허용 등)에 대한 대체 경로를 정의합니다.

## 6. 기술 아키텍처 제안
- **클라이언트**: React Native 기반 모바일 앱
  - Expo 또는 bare React Native 선택 가능
  - 카메라 모듈(바코드 스캔), 지리 정보(GPS), 푸시 알림 처리
- **백엔드**: Node.js + NestJS
  - GraphQL API로 모바일-백엔드 간 통신 단순화
  - Passport 기반 JWT 인증, 소셜 로그인 연동(선택)
  - 서드파티 책 정보 API(예: Kakao 책 검색, Google Books) 연동
- **데이터베이스**: PostgreSQL + PostGIS 확장으로 위치 데이터 처리
- **스토리지**: AWS S3 또는 호환 스토리지에 리뷰 사진 저장
- **실시간 기능**: Firebase Cloud Messaging을 통한 푸시 알림, 혹은 WebSocket 기반 실시간 알림 서버
- **인프라**: Docker 컨테이너화 → AWS ECS/Fargate 또는 Kubernetes 배포, Terraform으로 IaC 관리

## 7. 보안 및 개인정보 보호 고려 사항
- 위치 데이터는 기본적으로 시/군 단위로 저장하고, 상세 좌표는 선택적으로 암호화 저장
- 접속 로그 및 민감 정보는 별도 보안 저장소에 암호화하여 보관
- 책 소유권 이전 시 개인정보 공유 범위(연락처 공개 여부) 설정
- 커뮤니티 가이드라인 및 신고/차단 기능 제공

## 8. 단계별 로드맵
1. **컨셉 검증 (2주)**
   - 잠재 사용자 인터뷰, 핵심 플로우 와이어프레임 제작
   - 피드백 기반으로 MVP 범위 확정
2. **MVP 개발 (6주)**
   - 핵심 기능: 책 등록, 체크인, 지도 뷰, 후기 작성
   - 기본 알림 및 팔로우 기능
3. **베타 테스트 (4주)**
   - 소규모 독서 모임 대상 클로즈드 베타 진행
   - 버그 수정, 사용자 경험 개선, 분석 이벤트 정의
4. **정식 출시**
   - 앱스토어/플레이스토어 배포, 마케팅 캠페인 실행
   - 커뮤니티 운영 가이드라인 발표 및 온보딩 자료 제공

## 9. 향후 확장 아이디어
- AR 기반 "책 인증샷" 필터 제공
- 여행 중인 책을 위한 오프라인 픽업 스팟 연계(카페, 독립서점)
- 독서 모임/테마별 챌린지 기능
- 독립 작가와의 협업을 위한 특별 에디션 발행
